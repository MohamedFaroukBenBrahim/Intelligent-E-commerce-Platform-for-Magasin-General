# Intelligent-E-commerce-Platform-for-Magasin-General
Intelligent multi-service e-commerce platform developed for Magasin Général, featuring product and order management, recruitment services, AI-powered recommendation systems, chatbot integration, and a voice-enabled virtual assistant.
Magasin Général – Intelligent E-Commerce Platform
Overview

This project is an intelligent multi-service e-commerce platform developed for Magasin Général as part of an End-of-Program Project (PFE).

The platform was designed to modernize and enhance the online shopping experience by combining traditional e-commerce functionalities with Artificial Intelligence solutions. In addition to product management and online purchasing, the platform integrates recruitment services, intelligent recommendation systems, an AI chatbot, and a voice-enabled virtual assistant.

The objective of this project was to create a scalable, maintainable, and user-friendly ecosystem capable of serving both customers and administrators while introducing innovative AI-powered features.

Used for lip synchronization.

Responsibilities:

Used to create and animate the 3D avatar.

Responsibilities:

Character modeling
Character animation
Avatar optimization

## How to Run This Project

### 1. Clone the Repository

```bash id="q1v8x2"
git clone <repository-url>
cd project-folder
```

---

### 2. Backend Setup (Spring Boot)

```bash id="b7k2m1"
cd backend
mvn clean install
mvn spring-boot:run
```

Make sure to configure the required environment variables inside the backend configuration file (application.properties or .env), including database credentials and API keys.

---

### 3. Frontend Setup (Angular)

```bash id="t4p9x6"
cd frontend
npm install
ng serve
```

The application runs on:
http://localhost:4200

---

### 4. Flask AI Service

```bash id="f2c8d9"
cd flask-service
python app.py
```

Make sure Python dependencies are installed before running the service.

---

### 5. MinIO Server

Start MinIO for file storage (images, CVs, etc.):

```bash id="m8n3k5"
minio server <your-data-folder>
```

Ensure MinIO credentials are correctly configured in the backend.

---

### 6. Required Tools

* **FFmpeg**: Required for audio processing (must be installed and added to PATH)
* **Rhubarb Lip Sync**: Required for avatar lip synchronization

---

### 7. API Keys Configuration

Add the following API keys in backend configuration:

* Groq API (chatbot / Llama model)
* ElevenLabs API (voice generation)

---

### 8. Running the Full System

To run the project correctly:

1. Start MySQL database
2. Start MinIO server
3. Run Flask service
4. Run Spring Boot backend
5. Run Angular frontend
6. Ensure FFmpeg and Rhubarb are installed
7. Ensure API keys are configured

---

### 9. Notes

If any feature (chatbot, avatar, file upload, or recommendations) is not working, verify:

* API keys are correct
* MinIO is running
* Flask service is active
* External tools (FFmpeg, Rhubarb) are installed
